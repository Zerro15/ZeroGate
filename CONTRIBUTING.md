# CONTRIBUTING

Спасибо, что хотите помочь развитию ZerroGate! Следуйте этим простым правилам.

## Как начать
1. Сделайте форк репозитория и создайте ветку вида `feature/short-topic` или `fix/short-topic`.
2. Установите зависимости для backend (`pip install -r backend/requirements.txt`). Для Flutter поставьте зависимости через `flutter pub get`.
3. Перед отправкой PR запустите тесты:
   - Backend: `cd backend && pytest`
   - Flutter (если доступно окружение): `cd app && flutter test`

## Правила коммитов
- Сообщения коммитов на английском, краткие и описательные.
- Один PR — одна логическая задача.

## Код-стайл
- Python: следуйте PEP8, используйте тайп-хинты и русские комментарии, объясняющие логику.
- Flutter: аккуратные виджеты, избегайте лишней магии, подписывайте стейт понятными именами.

## Проверки
- Если добавляете новый эндпоинт, обновите `docs/api.md`.
- Если меняется архитектура, обновите `docs/architecture.md` и README при необходимости.
